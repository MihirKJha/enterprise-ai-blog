# 📖 About

The **Enterprise AI Engineering Blog** is a technical publication by **Mihir Jha**, focused on the intersection of Software Engineering, Cloud Architecture, and AI Engineering.

The blog explores practical engineering problems involved in designing, building, deploying, and operating modern distributed and AI-powered systems.

The emphasis is on **production engineering**, architecture, trade-offs, reliability, scalability, security, observability, and maintainability.

# ✍️ Article Format

Articles are written in Markdown and use page-level SEO metadata.

Example:

```markdown
---
title: Designing Production-Grade RAG Systems
description: >
  Explore production RAG architecture covering retrieval, reranking,
  evaluation, observability, security, latency, and cost optimization.
---

# Designing Production-Grade RAG Systems

Article content...
```

This keeps articles portable, version-controlled, and easy to maintain while allowing MkDocs to generate the public website.
